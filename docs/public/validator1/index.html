What these metrics mean
Agreement
Share of recent ledgers where this validator’s vote matched the ledger the network accepted. Scored by the XRPL.org observer (data.xrpl.org), not from this page’s host. Healthy operators sit near 100%. A drop is the first public sign the node is missing or disagreeing with closes.
UNL active
Whether this node has a usable Unique Node List — the set of validators it trusts to close ledgers — loaded and unexpired. It does not mean Cloud Syndicate is on the default XRPL UNL. Default-UNL membership is a separate, public-list question.
State
Proposing means the node is issuing validations (the healthy operating mode). Connected means it is on the peer network but not validating. Offline or unknown needs attention.
Sample age
Age of the newest sidecar reading from the validator’s localhost admin RPC (version, peers, proposing, UNL gauges). Fresh means the sidecar sample was ≤120s old when this page’s snapshot was published (the snapshot itself refreshes about every five minutes). Charts retain the window advertised by history.json (window_days); 30d / All show that retained window, not a fabricated longer series.
